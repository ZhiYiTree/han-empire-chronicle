# 汉 · 帝国纪事　第一卷：大风歌

把 45 集历史讲座「拆开重做」的交互式历史探索网站。

> **内容骨架**：王立群《百家讲坛 · 王立群读〈史记〉之〈大风歌〉》（CCTV-10，2011 年首播）
> **一手核验**：《史记》《汉书》

---

## 它解决什么问题

讲座视频和文稿是**线性**的。想弄明白「刘邦和韩信的关系是怎么一步步崩掉的」，你得来回翻好几集。

本项目把 45 集（约 33 万字）拆成结构化数据，让你可以按**时间、人物、关系、论点**任意横切。

## 功能

| 模块 | 说明 |
| --- | --- |
| **纪年** | 单轴垂直时间线（前 211 — 前 195），滚动逐个点亮，可按人物与级别筛选 |
| **事件三层阅读** | 同一事件分「故事 / 史书 / 解析」三层，观点与史料严格分开 |
| **人物档案** | 111 位，S / A / B 分级，含阵营、加入途径、专长、「才与疑」 |
| **关系链** | 17 条，含刘邦 × 韩信的完整八阶段演变 |
| **人物总评** | 自信 / 魅力 / 用人三组特质树，**每条论点都配一条「局限或反例」** |
| **史料溯源** | 60 处《史记》引文，逐字比对原文，标注已核状态 |
| **⌘K 检索** | 跨人物 / 事件 / 关系 / 讲坛 |

## 内容边界：严格区分三类东西

这是本项目最花力气的地方——**不让读者把「解释」误当成「史实」**。

| 类型 | 处理方式 |
| --- | --- |
| 公认史实 | 标注来源，可核验 |
| 史书记载的帝王传奇（蛟龙感生、斩白蛇、望云气等） | 标为「史书记载」，明确**不等于**可验证事实 |
| 王立群的解释与评价 | 一律标为「王立群观点」，**绝不与史实混同** |

节目「画外音」单独存储，不计入王立群个人观点。

数据层面 `historical_fact` 为 0 条——所有讲座原话都落在 `lecture_interpretation` / `lecture_evaluation`。

## 目录结构

```
han/
├── content/
│   ├── extracted/   45 集逐集抽取的结构化 JSON（3 个子任务并行精读产出）
│   ├── data/        归并后的数据层 persons / events / relations / lectures / sources / traits
│   └── shiji/       已抓取的《史记》原文 16 篇（简体，用于逐字核对引文）
├── site/            零构建静态站（双击 index.html 即可打开）
│   └── assets/
│       ├── js/data.js      打包后的数据层
│       └── img/people/     人物照片（{姓名}.jpg，缺失时回落到程序化头像）
├── docs/            内容审计、实体索引、研究计划与日志
└── *.py             数据管线脚本
```

## 本地运行

```bash
cd han/site
python -m http.server 8788
# 打开 http://127.0.0.1:8788/
```

**无需安装依赖、无需构建**。数据打包为 `data.js`（JS 变量而非 fetch JSON），所以直接双击 `index.html` 也能打开。

## 数据管线

```
逐字稿
  → 3 个子任务并行精读 45 集（每批 15 集）→ content/extracted/*.json
  → build_data.py        异名归一 + 实体归并
  → events_content.py    撰写「故事 / 史书 / 解析」三层
  → fetch_shiji.py       抓取《史记》原文
  → verify_quotes.py     逐条比对引文与原文（当前 60/60 全部吻合）
  → finalize_data.py     打包成 site/assets/js/data.js
  → smoke.js             自建 DOM 桩，遍历 253 条路由检查渲染异常
```

其他脚本：

- `query_shiji.py` — 关键词定位《史记》原文
- `patch_quotes.py` / `patch_quotes2.py` — 批量订正引文
- `build_photo_list.py` — 生成人物照片接入清单
- `crop_clipboard_photos.py` — 把 2×2 合并卡牌图裁成单张人物照片
- `rewrite_timeline.py` / `append_style.py` — 纪年页改版脚本

## 技术选型

刻意**没有**用框架：原生 HTML / CSS / JS + 数据打包成 JS 变量。

理由：零依赖、零构建，双击即开；数据层是纯 JSON，将来迁 Next.js 只是换个壳。
动效仅用原生 `IntersectionObserver` + CSS 过渡，未引入动画库。

视觉：黑漆 `#0d0b0a` / 朱 `#b83b2b` / 旧帛 `#d8cdbb` / 暗金 `#a8894f`，衬线宋体为主。

## 已知取舍

- 讲座集数按 **45 集**（实际播出版）编排。网上另有 48 集分法（多出「知人料事 / 善谋大事 / 千秋功过」），仅为目录条目，正文未找到可靠来源。
- 人物照片为 **AI 生成的示意性形象**，史书并无真实肖像传世。
- 未使用 TypeScript / 构建工具，代价是缺少类型检查。
