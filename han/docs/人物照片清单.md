# 人物照片接入清单

> 本文件说明：如何把人物照片放进《汉 · 帝国纪事》网站。
> 数据版本：人物 111 位（S 级 6 / A 级 14 / B 级 91）

## 怎么用（三步）

1. 把照片**命名为「姓名.jpg」**，例如 `刘邦.jpg`、`项羽.jpg`。
2. 放进目录 `han/site/assets/img/people/`。
3. 刷新网页即可。

**没放照片的人物不会开天窗**——会自动回落到「姓名首字 + 帛书纹样」的程序化头像，
所以可以只给重要人物配图，其余慢慢补。

## 规格建议

| 项 | 建议 |
| --- | --- |
| 比例 | 竖版 3:4（页面容器 132×172，原图建议 ≥ 600×800） |
| 格式 | `.jpg`（扩展名小写） |
| 构图 | 人物上半身居中，头部位于画面上 1/3 处 |
| 风格 | 画像、剧照、AI 生成图均可；页面已做轻微去饱和，暗色调素材更协调 |
| 命名 | 必须与下表的「姓名」**完全一致**（含异体字，如 `黥布.jpg`） |

> 注意：史书无真实肖像传世，任何配图都属于**示意性形象**。
> 若使用 AI 生成或影视剧照，建议在页脚或 README 注明来源。
